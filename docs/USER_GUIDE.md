# LostFile 使用指南

## 1. 首次启动

首次启动会显示引导窗口：

1. 阅读欢迎页（应用只保存文件元数据、不上传任何信息）
2. 勾选要索引的目录：下载目录 / 桌面 / 文档目录，或用「添加文件夹…」选择任意目录
3. 点击「开始使用」→ 立即在后台扫描

之后可在 **设置 → 索引目录** 中随时添加、移除目录，或重新扫描。LostFile **不会自动扫描整个磁盘**。

## 2. 索引管理

- **增量更新**：重新扫描时只更新有变化的文件并删除已不存在的记录
- **暂停 / 继续 / 取消**：扫描期间窗口顶部出现进度条与按钮，取消后已索引的数据仍保留
- **排除设置**（设置 → 索引目录）：可排除指定文件夹、排除指定扩展名（如 `jpg png tmp`）
- 扫描错误（无法访问目录、扫描期间被删除的文件）自动跳过并计数，不中断整体扫描

## 3. 搜索方式一：自然语言描述

在顶部搜索框输入一句话，例如：

| 你说的话 | 解析结果 |
| --- | --- |
| 昨天下载的 PDF，大概 3MB | 类型 PDF · 修改时间≈昨天 · 大小 2–5MB · 位置 下载目录 |
| 上周修改的图片 | 类型 图片 · 修改时间 上周 |
| 下载目录里超过 100MB 的视频 | 位置 下载目录 · 大小 >100MB · 类型 视频 |
| 最近一个月创建的 Word 文档 | 类型 Word · 创建时间 最近 30 天 |
| 桌面上那个很大的视频文件 | 位置 桌面 · 类型 视频 · 大小 >100MB（“很大”的近似） |
| D盘上的压缩包 | 位置 D 盘 · 类型 压缩包 |

**解析后操作：**

- 条件以标签显示，点击标签上的 ✕ 可移除该条件
- 「在筛选器中修改」：把条件填入筛选面板，精确调整后搜索
- 「确认并搜索」：直接按当前标签搜索
- 未能理解的部分会显示提示：“未能理解的部分已忽略：……”

**支持的规则摘要：**

- 时间：今天 / 昨天 / 前天 / 本周 / 上周 / 最近 N 天 / 最近一个月 / N 月 N 日 / 今年…；出现“创建/新建”按创建时间，否则默认按修改时间（标签中会写明）
- 大小：“大概 3MB”自动放宽为 2–5MB；“超过/大于/以上”“小于/不足/以下”“1–10MB”“2到5MB”
- 类型：PDF、Word、Excel、PPT、图片/照片、视频、音频/音乐、压缩包、安装包、文本、代码、文档…
- 位置：下载目录、桌面、文档目录、C盘/D盘、具体路径

## 4. 搜索方式二：多条件筛选

点击「筛选」展开面板，所有条件均为下拉选择，无需学习任何语法：

- 文件类型 / 扩展名（如 `mp4 zip`）
- 文件名关键词（模糊匹配，可选）
- 时间范围 + 按修改/创建/任一（自定义日期可选具体到天）
- 大小范围（预设档位或自定义 MB 数值）
- 文件位置（下载/桌面/文档/已索引目录/自定义目录）

点击「搜索」执行；「重置」清空面板。

## 5. 结果与匹配原因

- 结果按相关度排序：文件名精确匹配 > 前缀 > 包含 > 路径包含，相同分数较新的排前
- 列：文件名、状态（存在/不存在）、类型、大小、修改时间、创建时间、所在目录
- 点击某行，下方「匹配原因」面板说明它满足哪些条件；文件已被移动/删除时文件名带删除线并提示
- 结果过多时只显示前 N 条并提示细化条件；「在结果中筛选」可在当前结果内即时过滤

**操作按钮**：打开 / 打开所在文件夹 / 复制完整路径 / 属性 / 加入收藏。

**注意：LostFile 不提供批量删除，也绝不会修改、移动或删除你的任何原始文件。**

## 6. 最近打开（可选，默认关闭）

设置 → 隐私 → 勾选「启用“最近打开”导入」时，会先弹出说明：该功能读取 Windows“最近使用文件”列表的快捷方式，仅提取目标路径与时间，来源应用显示“未知”；不会读取文件内容、浏览器密码或 Cookie。开启后工具栏「最近打开」可查看列表并执行打开/定位/复制路径。

## 7. AI 解析按钮（可选，默认关闭）

搜索框旁有一个「AI 解析」按钮：把你输入的**描述文字**发给你自己配置的 AI 服务（OpenAI 兼容端点），由它先判断**你描述的东西到底是什么**（例如某个下载来的项目名、游戏名、软件名），给出这个名字在本地文件名/文件夹名里可能出现的写法，然后**直接在本机搜索**并展示结果——不需要你再点一次「确认并搜索」。

- 搜索完成后会在条件栏显示「AI 分析：……；已按相关名称直接搜索：……」，你可以看到 AI 是怎么理解你的描述的；
- 条件标签仍然保留：不满意可点「✕」移除某个条件，或「在筛选器中修改」后重新搜索；
- 首次点击会弹出隐私说明（只发送描述文字；不上传文件名/路径/索引），确认后才启用；
- 先在 **设置 → AI** 填好服务端点、模型名称与 API Key（默认已填 DeepSeek 端点，常用只需补 Key；本地 Ollama 用户端点填 `http://localhost:11434/v1`、Key 留空）；
- API Key 用 Windows DPAPI 加密保存在本机，换用户/重装系统后需重新填写；
- 解析失败、超时或返回异常时，自动回退本地规则解析并同样直接搜索，且如实提示你用了哪种方式。

## 8. 正文内容检索（可选，默认关闭）

**设置 → 维护 → 勾选「启用正文内容检索」**（首次弹窗说明）：应用会在本机提取纯文本文件（txt/md/日志/csv/配置/源代码等）**开头最多 16KB** 的内容建立全文索引；node_modules、site-packages、.git、build、dist 等依赖/构建目录会被跳过，以避免索引体积膨胀。

- 搜索时，正文含关键词的文件会出现在分组树最顶部的「**内容命中**」组，鼠标悬停可看命中片段；正式结果表口径不变（仍是文件名/路径匹配）；
- 只读纯文本，不解析 Office/PDF、不读图片视频；一切数据留本机；
- **已知限制**：2 个字的中文词无法用于正文匹配（文件名的 2 字词不受影响）；
- 可随时关闭；「重建内容索引」清空重来；进度在维护页实时显示。

## 9. 重复文件检测（可选，默认关闭）

**设置 → 维护 → 勾选「启用重复文件检测」**（首次弹窗说明）：后台按内容哈希找出内容完全相同的文件（名字不同也算），不保存文件正文、绝不上传。

- 工具栏「**重复文件**」里按组查看：每组显示文件数、可释放空间；右键可打开/定位/复制路径/删除到回收站（单个确认，绝不批量删除）；
- 打开对话框时若检测尚未完成，先点「开始/继续检测」，结果实时刷新；
- 超过 2GB 的文件自动跳过；「全部重新检测」清空哈希重算。

## 10. 本地语义搜索（可选，默认关闭）

**设置 → 语义 → 勾选「启用“语义相关”分组」**：启用时首次会**联网下载一次**向量模型（约 24MB，存到数据目录 `models/`，确认弹窗会写明来源与大小），之后全程离线。

- 搜索时，文件名“意思相近”的文件（即使名称里没有你的关键词）会出现在分组树顶部的「**语义相关**」组，悬停可见相似度；
- 只给**文件名**编码，不读取文件内容；百万文件的向量约 512MB（内存映射，不占满内存）；
- 后台增量构建，进度见设置页；「删除向量数据」可一键腾出空间，「重建向量索引」重新构建。

## 11. 隐私与数据

| 操作 | 位置 | 效果 |
| --- | --- | --- |
| 清除全部索引 | 设置 → 隐私 | 删除索引记录与目录列表（不影响磁盘文件） |
| 清除搜索历史 | 设置 → 隐私 | 删除全部本地搜索记录 |
| 退出时是否保留索引 | 设置 → 隐私 | 关闭后每次退出即清除索引 |
| 便携模式 | 默认开启（exe 旁 data/） | 数据随程序走，删除文件夹即清除一切 |

完整隐私说明见 [PRIVACY.md](PRIVACY.md)。

## 12. 主题

工具栏「主题」按钮切换浅色/深色；设置 → 外观 可选跟随系统。

## 13. 常见问题

**Q：为什么有些文件搜不到？** 只有已索引目录中的文件才会被搜索；检查 设置 → 索引目录 是否包含该目录、是否被排除。

**Q：提示“索引数据库已重建”？** 数据库损坏时自动备份重建（`lostfile_index.db.corrupt-<时间戳>`），重新扫描即可恢复。

**Q：结果中显示“不存在”？** 文件在索引后被移动、重命名或删除。可以「打开所在文件夹」查看。

**Q：如何完全卸载？** 便携模式下直接删除整个程序目录；普通模式下删除程序并清空 `%APPDATA%\LostFile`。

**Q：需要联网吗？** 默认不需要：搜索、解析、索引全部本地完成。会联网的只有三个**默认关闭**的可选功能——「在线搜索 GitHub」（只发送你输入的关键词）、「AI 解析」（只发送你输入的描述文字到你自己配置的服务）、首次启用语义搜索时的模型下载（约 24MB，仅一次）。均不会上传本地文件名、路径或索引内容。
